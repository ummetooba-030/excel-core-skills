# Excel Core Skills

A set of practical Excel projects covering reporting, data management, and dashboard building — built to show real working knowledge of Excel as a business tool, not just formulas in isolation.

## Projects in this repo

### 📅 Daily Sales Report Template
A month-by-month sales tracking template (Jan–Dec sheets) that rolls up into a consolidated annual view. Built for repeatable daily use, not a one-off report.

### 📦 Inventory Management
A structured system tracking Products, Transactions, and live Inventory levels, with a PivotTable view for quick stock analysis. Shows how to link transactional data to real-time inventory positions.

### 📊 Sales Dashboard
An interactive dashboard built on a 1,200+ row transactional dataset, breaking down profit by country and product, units sold by month, and profit trends over time. Demonstrates PivotTable-driven analysis and dashboard design, not just static charts.

## Skills demonstrated

- Template design for repeatable business reporting
- Data structuring across linked sheets (Products → Transactions → Inventory)
- PivotTables for dynamic summarization
- Dashboard building from raw transactional data
- Working with larger, realistic datasets (1,000+ rows)
